## Ограничения проверки среды

На компьютере не обнаружен Docker CLI, WSL не установлен. Две попытки запуска переносимого PostgreSQL 18/17 остановились в `initdb` из-за ошибок файлового доступа среды (`postmaster.pid` / Bad file descriptor). Рабочая проверка PostgreSQL-сервера и `docker compose up` **не выполнена**. Скомпилированная SQL-миграция не заменяет такую проверку.

Для браузерной проверки временно использовалась отдельная файловая SQLite в `work/`, без изменения PostgreSQL-конфигурации поставляемого приложения. Официальный путь запуска — Docker Compose с PostgreSQL 17. Повторный прогон против отдельной PostgreSQL-БД описан в README.

Mailpit описан в Compose, но сам контейнер в этой среде не запускался. Внешний почтовый аккаунт не подключался; настоящая доставка в интернет не проверена.

В тестовом окружении отмечено предупреждение устаревшего алиаса BlockingPortal из Starlette/AnyIO; оно не влияет на результаты. Экспортные формы — собственные шаблоны, поскольку в предоставленном PDF отсутствуют образцы заказчика. Полная проверка нормативов ЕВСК не заявляется.
