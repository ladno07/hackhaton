# Проверка реализации · 26 октября 2026

## Подтверждено

- Python 3.12: **19 тестов пройдены за 16,16 с**. Интеграционные API-тесты на изолированной SQLite в памяти с включёнными внешними ключами. Проверяется бизнес-логика и ограничения доступа, а не только возврат HTTP 200.
- Уведомления дополнительно проверены на изоляцию по активной роли: внутренние заявки федерации не видны при переключении того же аккаунта в кабинет спортсмена.
- React/TypeScript: production-сборка Vite успешно завершена. Разделение bundle на framework/data/charts.
- `npm audit`: 0 уязвимостей после обновления Axios, React Router, Vite, PostCSS и парсера селекторов. `package-lock.json` сохранён.
- Alembic: выполнены upgrade → сравнение с метаданными моделей (без расхождений) → downgrade → upgrade на изолированной SQLite.
- PostgreSQL: успешно скомпилирован SQL начальной миграции в offline-режиме; файл `initial-schema-postgresql.sql`.
- Браузер: вход, создание соревнования через форму, открытие регистрации, переключение роли без входа, заявка спортсмена, одобрение федерацией, закрытие, ввод 875 баллов и публикация. Результат появился в рейтинге как 40 рейтинговых баллов. Затем сохранён состав сборной.
- Визуальная проверка desktop-интерфейса и ширины 390 px. Таблицы имеют горизонтальную прокрутку, меню выдвижное. Скриншоты сохранены в `screenshots/`.
- Экспорт PDF: настоящий протокол из API сформирован, отрендерен PDFium и просмотрен; кириллица и таблица восьми участников отображаются корректно.
- DOCX/XLSX: выгрузки проверены как корректные OpenXML-архивы.
- Почта: тест поднимает настоящий локальный SMTP-сервер, принимает MIME-письма от `smtplib` и проверяет фиксацию успешной доставки в БД. Тест не отправляет письма во внешние почтовые ящики.

## Ограничения проверки среды

На компьютере не обнаружен Docker CLI, WSL не установлен. Две попытки запуска переносимого PostgreSQL 18/17 остановились в `initdb` из-за ошибок файлового доступа среды (`postmaster.pid` / Bad file descriptor). Рабочая проверка PostgreSQL-сервера и `docker compose up` **не выполнена**. Скомпилированная SQL-миграция не заменяет такую проверку.

Для браузерной проверки временно использовалась отдельная файловая SQLite в `work/`, без изменения PostgreSQL-конфигурации поставляемого приложения. Официальный путь запуска — Docker Compose с PostgreSQL 17. Повторный прогон против отдельной PostgreSQL-БД описан в README.

Mailpit описан в Compose, но сам контейнер в этой среде не запускался. Внешний почтовый аккаунт не подключался; настоящая доставка в интернет не проверена.

В тестовом окружении отмечено предупреждение устаревшего алиаса BlockingPortal из Starlette/AnyIO; оно не влияет на результаты. Экспортные формы — собственные шаблоны, поскольку в предоставленном PDF отсутствуют образцы заказчика. Полная проверка нормативов ЕВСК не заявляется.

## Исправление сохранения существующего профиля

Из запроса редактирования удалено серверное поле `athlete_id` внутри дисциплин. Для записи передаются только `discipline_id`, `start_year`, `end_year`. Проверено сохранение существующего профиля через браузер: PUT вернул 200 OK, данные повторно загружены. Production-сборка frontend прошла.
