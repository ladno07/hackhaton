# Задачи по кейсу «Единая цифровая платформа ФСП Оренбургской области»

Состояние на 26.10.2026. Есть рабочий MVP: FastAPI + PostgreSQL + React, 26 таблиц, 4 кабинета с переключением ролей, полный цикл соревнования, разряды, рейтинг, сборная, выгрузки PDF/DOCX/XLSX, уведомления и журнал действий. Все 8 обязательных блоков закрыты в базовом виде. Доп. сценарии Д1–Д12 не начаты, ограничения описаны в [README.md](README.md).

## A. Критично для сдачи

- [ ] **Нет git-репозитория.** На чекпоинте №3 нужен репозиторий: сделать `git init`, проверить, что `.env` в `.gitignore`, и запушить.
- [ ] **Запуск в Docker не проверялся ни разу** (см. [docs/VERIFICATION.md](docs/VERIFICATION.md)). Прогнать `docker compose up --build`, `seed --demo`, тесты на PostgreSQL и сквозной сценарий.
- [ ] **Нет внешнего канала уведомлений, который можно показать.** Сейчас есть только почта через Mailpit, он ничего не доставляет наружу. Добавить Telegram-бота: привязка через `/start` с кодом из кабинета, отправка через ту же очередь `notifications`.
- [ ] Поднять стенд или записать демо-видео на 2–3 минуты (чекпоинт №2).
- [ ] Подготовить материалы к чекпоинту №1: проблема, отличия, сценарии MVP, выбранные доп. сценарии, стек.

## B. Доработка обязательной части

- [ ] **Положение:** сейчас хранится только ссылкой. Нужна загрузка файла и скачивание спортсменом.
- [ ] **Возрастные группы:** сейчас только `min_age/max_age`. Нужен справочник групп по правилам вида спорта (юноши/девушки, юниоры, мужчины/женщины) и подсказка спортсмену «вы проходите по возрасту».
- [ ] **Статус и тип соревнования:** в поле `level` смешаны статус и уровень для рейтинга. Нужны отдельно статус (региональное / межрегиональное / всероссийское) и тип из справочника; уровень для рейтинга вычислять из пары «статус + тип».
- [ ] **Протокол:** нет одинаковых мест, командных составов и исправления после публикации (версии протокола).
- [ ] **Карточки тренеров и судей:** нет полноценного создания, редактирования и архивации.
- [ ] **Профиль спортсмена:** сверить с кейсом все поля (ФИО, дата рождения, муниципалитет, организация, дисциплины, год начала, тренеры, разряд и срок, законный представитель). Нет поля «пол» (нужно для групп и Д4). Нет раздела «Документы» с согласиями: просмотр и скачивание своего согласия.
- [ ] **Дашборд федерации:** проверить, что в блоке «Требует внимания» есть все пункты: заявки на модерации, заявки на разряды и категории, истекающие разряды и категории, сроки отчётов.
- [ ] **Тренер:** сводка выступлений по каждому подопечному отдельным экраном.
- [ ] **Судья:** разделить «Назначения» (будущие) и «Мои соревнования» (прошедшие), добавить отчёт о соревнованиях, где он работал.
- [ ] **Численность по годам:** сейчас считается по текущей организации. Нужна история переходов между организациями (сделать или назвать как ограничение).
- [ ] **Шаблоны документов:** привести протокол, приказ и отчёты ближе к официальным формам (шапка, подписи, реквизиты ФСП).
- [ ] **Стиль ФСП:** сверить цвета и шрифты с fsp-russia.com, добавить логотип, проверить вид на телефоне и планшете.

## C. Доп. сценарии (по выбору, от простых к сложным)

- [ ] **Д10. Справка об участии с QR-кодом.** Номер, QR и публичная страница проверки. Займёт 2–3 часа, хорошо смотрится на демо.
- [ ] **Д11. Навигатор для новичка.** Публичная страница без входа: дисциплины, где заниматься, ближайшие соревнования.
- [ ] **Д9. Кабинет Минспорта.** Новая роль только на чтение, в основном настройка прав доступа.
- [ ] **Д12. Документы о судействе.** Состав коллегии и отчёт судьи, почти всё уже есть.
- [ ] **Д7. Личный путь и справочник понятий.** Опирается на существующие правила ЕВСК.
- [ ] **Д6. Показатели развития.** Отчёт о численности есть; добавить источники и прикрепление документов.
- [ ] **Д8. Премии Губернатора.** Справочник сумм, автоматический список претендентов, статусы. Напоминание до 1 февраля уже есть.
- [ ] **Д5. Апелляции и нарушения.** Сочетается с исправлением протокола из блока B.
- [ ] **Д3. Организации, группы, журнал занятий.** Карточка организации (тип, лицензия, программы), учебно-тренировочные группы по этапам, зачисление и перевод, журнал занятий с подтверждением. Данные идут в отчёт о динамике. Трудоёмко.
- [ ] **Д4. Нормативы и аттестация по ФССП.** Справочник нормативов ОФП/СФП с порогами по этапу, дисциплине и полу, автоматическое сравнение результатов, готовность к переводу на следующий этап, история. Трудоёмко, нужно поле «пол».
- [ ] **Д2. Интеграции.** Токены доступа с ограничением прав, вебхуки (соревнование опубликовано, заявка одобрена, протокол опубликован), импорт результатов, описание API. Трудоёмко.
- [ ] **Д1. Региональный ФСП ID (OpenID Connect).** Регистрация клиентов, authorization code + PKCE, страница согласия, discovery, userinfo, тестовый клиент. Самое трудоёмкое.
