# Задачи по кейсу «Единая цифровая платформа ФСП Оренбургской области»

Состояние на 28.10.2026. Есть рабочий MVP: FastAPI + PostgreSQL + React, миграции до 0023, 5 кабинетов с переключением ролей, полный цикл соревнования, разряды, рейтинг, сборная, выгрузки PDF/DOCX/XLSX, уведомления и журнал действий. Все 8 обязательных блоков представлены в базовом виде; реализованы дополнительные сценарии Д2–Д12. Д3 добавлен в текущий рабочий каталог; ограничения описаны в [README.md](README.md). Код репозитория: [ladno07/hackhaton](https://github.com/ladno07/hackhaton).

## B. Доработка обязательной части

6. [x] **Положение:** загрузка файла федерацией и скачивание спортсменом (миграция 0002).
7. [x] **Возрастные группы:** справочник групп по правилам вида спорта (юноши/девушки, юниоры, мужчины/женщины), проверка допуска и подсказка спортсмену «вы проходите по возрасту» (миграция 0003).
8. [x] **Статус и тип соревнования:** отдельно статус (региональное / межрегиональное / всероссийское) и тип из справочника; уровень для рейтинга вычисляется из пары «статус + тип» (миграция 0004).
9. [x] **Протокол:** одинаковые места, командные составы и исправление после публикации через редакции протокола (миграция 0005).
10. [x] **Карточки тренеров и судей:** создание федерацией (с учётной записью или ролью существующему пользователю), редактирование федерацией и владельцем в «Моём профиле», мягкий архив с причиной и восстановлением; контакты видны только федерации и владельцу (миграция 0006).
11. [x] **Профиль спортсмена:** сверены поля по кейсу: ФИО, дата рождения, пол, муниципалитет, организация, дисциплины и годы занятий, тренеры, текущий разряд и срок действия, законный представитель. В «Моём профиле» добавлены «Документы»: просмотр и скачивание PDF выписок из записи собственного согласия и согласия представителя. Доступ только владельцу; выписка содержит сохранённые версию и время принятия, не подменяет подписанный бланк.
12. [x] **Дашборд федерации:** блок «Требует внимания» на обзоре федерации (`GET /api/dashboard/attention`): заявки на соревнования по турнирам, заявки на разряды и категории, разряды и категории, истекающие в ближайшие 30 дней (как в уведомлениях, без архивных судей), невыполненные сроки отчётов с отметкой просрочки и срок ходатайств на премии Губернатора.
13. [x] **Тренер:** сводка выступлений по каждому подопечному отдельным экраном.
14. [x] **Судья:** разделить «Назначения» (будущие) и «Мои соревнования» (прошедшие), добавить отчёт о соревнованиях, где он работал.
15. [x] **Численность по годам:** хранится история переходов между организациями (`athlete_organizations`), отчёт считает организацию по ней. Муниципалитет в разрезе — текущий.
16. [x] **Шаблоны документов:** протокол, приказ и отчёты собираются по единому бланку (`services/documents.py`): шапка с реквизитами ФСП, дата/место/номер, подписи с расшифровкой; приказ — проект с приложением.
17. [x] **Стиль ФСП:** сверить цвета и шрифты с fsp-russia.com, добавить логотип, проверить вид на телефоне и планшете.

## C. Доп. сценарии (по выбору, от простых к сложным)

18. [x] **Д10. Справка об участии с QR-кодом.** PDF на едином бланке с протоколом, номер справки, QR и публичная страница проверки номера и статуса без персональных данных; полная справка доступна только авторизованным пользователям с правом доступа. Поддерживаются редакции протокола и проверка актуальности справки.
19. [x] **Д11. Навигатор для новичка.** Публичная страница `/start` без входа (`GET /api/public/navigator`): шаги «с чего начать», дисциплины с описанием, где заниматься с фильтром по дисциплине и муниципалитету, ближайшие соревнования; без персональных данных.
20. [x] **Д9. Кабинет Минспорта.** Роль `ministry` только на чтение (миграция 0008): обзор, календарь, реестр без документов, протоколы, разряды, рейтинг и сборная, аналитика с выгрузками. Любые изменения запрещены на уровне проверки роли; назначает роль только федерация.
21. [x] **Д12. Документы о судействе.** «Состав судейской коллегии» (гриф «УТВЕРЖДАЮ», должности, категории на дату соревнования) и «Отчёт главного судьи» (заявки, участники, призёры, исправления протокола) на бланке ФСП в PDF/DOCX/XLSX; доступ федерации, Минспорту и судьям коллегии, отчёт — только главному судье.
22. [x] **Д7. Личный путь и справочник понятий.** Опирается на существующие правила ЕВСК.
23. [x] **Д6. Показатели развития.** Показатели реестра с описанием источника; внесённые показатели с обязательным источником и подтверждающими документами (до 10 файлов); отчёт на бланке ФСП в PDF/DOCX/XLSX; Минспорт только читает.
24. [x] **Д8. Премии Губернатора.** Справочник сумм по уровню соревнования и месту; автоматический список претендентов из опубликованных протоколов (одна премия в год по лучшему достижению, отстранённые не выдвигаются); статусы «претендент → в ходатайстве → присуждена / отказано» с номером распоряжения и причиной; ходатайство на бланке ФСП в PDF/DOCX/XLSX; напоминание до 1 февраля ведёт на страницу; Минспорт только читает.
25. [x] **Д5. Апелляции и нарушения.** Нарушения с санкцией «предупреждение» или «отстранение до даты» (отстранение пишется в реестр, отмена возвращает оставшееся); апелляции спортсмена или тренера на строку протокола (3 дня после публикации редакции) и на решение о нарушении (10 дней); удовлетворённая апелляция на результат публикует новую редакцию протокола с основанием «Апелляция № …», на нарушение — отменяет его; уведомления, блок «Требует внимания», отчёт главного судьи, журнал апелляций в PDF/DOCX/XLSX; судьи коллегии и Минспорт только читают (миграция 0017).
26. [x] **Д3. Организации, группы, журнал занятий.** Реквизиты лицензии и программы организации; группы по этапам с тренером и вместимостью; зачисление по FSP ID, переводы и отчисления по приказу с историей; расписание с временем, часовым поясом, адресом или ссылкой и подготовкой; переносы, отмены, уведомления и напоминания; журнал после завершения занятия с подтверждением спортсменом и запросами исправления; динамика групп, посещений и подтверждённых часов, экспорт PDF/DOCX/XLSX. Минспорт только читает (миграции Д3, общий head 0023). [Сценарий и ограничения](docs/TRAINING_GROUPS.md).
27. [x] **Д4. Нормативы и аттестация по ФССП.** Справочник нормативов ОФП/СФП с порогами по этапу (НП, УТ, ССМ, ВСМ), дисциплине и полу; результаты вносит тренер или федерация, каждая попытка сравнивается с порогом; готовность к переводу на следующий этап — все применимые нормативы за 365 дней, разряд КМС/МС для ССМ/ВСМ, нет отстранения, указан пол; перевод приказом федерации с основанием, история попыток и переводов, уведомления, блок «Требует внимания», ведомость в PDF/DOCX/XLSX; Минспорт только читает (миграция 0018).
28. [x] **Д2. Интеграции.** Токены доступа с ограничением прав (хранится только хеш, срок, отзыв, журнал), вебхуки (соревнование опубликовано, заявка одобрена, протокол опубликован) с HMAC-подписью, outbox и повторами, импорт результатов из CSV/JSON с проверкой без сохранения, API `/api/v1` и [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md) (миграция 0019).
29. [ ] **Д1. Региональный ФСП ID (OpenID Connect).** Регистрация клиентов, authorization code + PKCE, страница согласия, discovery, userinfo, тестовый клиент. Самое трудоёмкое.
